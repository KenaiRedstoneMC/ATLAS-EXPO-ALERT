# ATLAS EXPO ALERT

Aplicación Android para recibir notificaciones de las actividades de ATLAS EXPO 2026.

- Programa del 21 y 22 de noviembre, incluidas las sesiones después de medianoche.
- Avisos 15, 10 y 5 minutos antes y al comenzar.
- Zona horaria Europe/Madrid.
- Android 8.0 o superior.
- Compilación automática mediante GitHub Actions.

## Descargar la APK
Cuando termine una compilación, abre **Actions**, selecciona el flujo **Build ATLAS EXPO ALERT APK**, entra en la ejecución correcta y descarga el artefacto `ATLAS-EXPO-ALERT-APK`.

## Permisos
Al abrir la app, concede permiso de notificaciones. En Android 12 o posterior, permite alarmas exactas si el sistema lo solicita. Algunos fabricantes pueden limitar las alarmas en segundo plano por el ahorro de batería.

## Nota
Las horas del programa están configuradas en hora local de Madrid. Revisa la fecha y hora del dispositivo antes del evento.
